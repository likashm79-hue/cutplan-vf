# CutPlan v1.6.2 verification report

Date: 13 November 2026

## Change delivered

- Increased the normal in-box label target from 10 pt to 11.5 pt (+15%). This is a modest increase, not the oversized 20 pt setting tried in v1.6.0.
- Both part references and dimension values use the 11.5 pt target when their panel has enough room.
- All text remains inside the corresponding part rectangle. No external callout/reference schedule is rendered.
- Existing strict small-panel rule remains: either source dimension below 90 mm uses combined Length × Width notation; exactly 90 mm remains regular.
- Adaptive reduction remains in place only when the panel cannot contain the target-size label. An in-box compressed line is the last resort for exceptionally small parts.
- No optimizer geometry, input values, banding calculations, parser behavior or manual-entry workflow changed.

## UI verification coverage

- Regular 1200 × 480 panel uses separate horizontal and vertical dimensions and all three text lines target 11.5 pt when they fit.
- Panels with a dimension below 90 mm retain combined Length × Width notation.
- A panel with one dimension exactly 90 mm retains regular edge-aligned notation.
- Small and very small panels still keep every label inside their own rectangles, adapting only when needed.
- No external callout schedule appears on screen or in print.
- Chromium page reported no JavaScript errors; an A4 PDF was generated and inspected.
