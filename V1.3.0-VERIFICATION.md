# CutPlan v1.3.0 verification report

Date: 11 November 2026

## Change delivered

- Small parts whose longest side occupies 45 mm or less at the drawing's actual print scale are detected in the shared drawing-label helper.
- Those small parts use a compact two-line in-panel label: part reference, followed by the original **Length × Width** value (e.g. `250 × 180` (dimensions in mm)).
- The compact label stays horizontal and uses the normal target font size. It does not shrink the type to fit separate dimensions along the two panel edges.
- If even the combined label cannot fit at the normal font size, the part uses an in-panel numbered marker and the adjacent schedule shows its reference and combined Length × Width value.
- Larger panels retain the previous in-panel reference and side-aligned dimension labels.
- The small-part schedule remains visible in print media for the very tiny fallback case.

## Threshold

The threshold is based on printed size, not raw source dimensions: `max(panel width, panel height) × print scale ≤ 45 mm`. This adapts to different board dimensions and print scales.

- A 250 × 180 mm panel is shown with a horizontal two-line label: reference and `250 × 180` (dimensions in mm). Both lines use the same normal target font size; neither dimension is rotated or placed along a side.

- A 1200 × 480 mm panel retains its existing edge-aligned dimension labels.
- No browser page errors occurred.
- Print-media emulation confirms the small-part schedule remains visible for the tiny-part fallback.
