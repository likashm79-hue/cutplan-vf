# CutPlan v1.4.0 verification report

Date: 11 November 2026

## Change delivered

- Removed the repeated `mm` suffix from part dimension labels in board drawings and the associated part callout schedule. Explicit units remain in data-entry controls, cutting-list headings, sheet settings, calculations and banding summaries.
- Changed small-panel detection from print-scaled board size to source dimensions. A row uses combined `Length × Width` notation only if `length < 90` mm OR `width < 90` mm.
- The threshold is strict: a dimension of exactly 90 mm is treated as regular.
- Small panels use one horizontal combined dimension line with the reference, when the normal-size text fits. If the panel is too narrow or short for it, the part receives a marker and the schedule gives its combined `Length × Width` value without `mm`.
- When both dimensions are at least 90 mm, the part retains separate horizontal/vertical edge-oriented labels. If a label needs callout fallback, the schedule says `Length <value> · Width <value>` instead of using combined notation.
- No optimizer geometry, input values, or banding calculations were changed.

- A panel with width 89 mm triggers combined notation even when length is 500 mm.

- A larger 1200 × 480 mm panel retains separate side-aligned dimensions.
