# CutPlan v1.2.0 verification report

Date: 10 November 2026

## Feature delivered

- Added an always-visible **＋ Add Panel** action beside the main cutting-list table. It remains available when the PDF/Image tab is selected after importing a document.
- Added a complete manual-entry dialog for reference, length, width, quantity, rotation, 0.8 mm length/width edge counts and 2 mm length/width edge counts.
- Added **Add & Add Another** for consecutive manual panel entry. The form stays open and proposes the next unused `MANUAL-###` reference.
- Manual rows are appended to the end of the current list; pre-existing imported rows and their order remain unchanged.
- Manual rows use the same data model as imported rows and therefore appear in the main list and Row Editor, contribute to piece and edge-banding totals, and are sent to the existing optimizer and PDF layout.
- Reference uniqueness, whole-number dimension ranges, quantity range and band-count ranges are validated.
- The older Manual tab's Add Panel button now opens the same full form, avoiding the old default-only row insertion.

## Manual-entry browser coverage

- PDF/Image import is active, then Add Panel is used without switching tabs.
- Imported references remain in the original order; manual rows are appended.
- Reference, dimensions, quantity, rotation and both banding materials are saved.
- Add & Add Another retains the dialog and generates a fresh manual reference.
- A newly added panel is reachable in the existing Row Editor, including its manual-entry source note.
- Duplicate references and fractional dimensions are rejected with an explanation.
- Optimizer run includes the manually added panel quantities and produces a valid plan.

## Verification boundary

These tests verify manual entry integration with the existing v1.0.0 codebase and browser workflow. As with imported cutting lists, users should verify all dimensions, quantities, edge-banding counts and rotation rules against the workshop source before production cutting.
