# CutPlan v1.6.1 verification report

Date: 13 November 2026

## Change delivered

- Reduced the oversized v1.6.0 20 pt label target to a moderate **10 pt** target.
- Kept regular panel references and dimensions inside the part rectangle. When they fit, regular panels retain separate horizontal width-edge and vertical length-edge labels.
- For small panels (either source dimension strictly below 90 mm), uses combined `Length × Width` notation inside the part.
- If regular edge-aligned labels do not fit at the target size, falls back to a combined `Length × Width` label inside that same rectangle.
- For unusually small panels, adaptively reduces text size. As a last resort, uses a compressed in-box single-line label.
- Removed the external part-label schedule from the rendered board layout and PDF. No marker is used to point outside the board.
- Removed the reserved side schedule column so the board has the full available print width.
- No changes to optimizer geometry, cutting measurements, edge-banding counts, parser or manual Add Panel behavior.
